# ConnectHub

## Task 2 - Social Media Platform

ConnectHub is a mini social media platform developed as part of the CodeAlpha internship Task 2.

## Features

- User registration and login
- User profiles
- Posts and comments
- Like and follow functionality
- Authentication
- Database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Project Structure

- `config/` - Configuration files
- `middleware/` - Authentication and middleware
- `models/` - Database models
- `public/` - Frontend files
- `routes/` - Application routes
- `uploads/` - Uploaded files
- `server.js` - Main server file
- `seed.js` - Database seed file
